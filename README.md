# PhoneCam 1.1

Телефон Android как виртуальная веб-камера Windows. Локальный Wi-Fi, один небольшой EXE, APK без рекламы и аккаунта. Видео без звука.

## Быстрый запуск

1. Установи `PhoneCam.apk` на телефон Android 7.0 или новее. Если установлен старый отладочный PhoneCam, сначала удали его: новый APK подписан постоянным release-ключом, подпись отличается.
2. Подключи телефон и ПК к одной обычной Wi-Fi сети. Гостевая сеть может запрещать обмен между устройствами.
3. Открой PhoneCam на телефоне, выбери фронтальную или основную камеру, нажми **Включить камеру** и разреши доступ к камере. Уведомления желательны, но отказ не мешает передаче.
4. Запусти `PhoneCam.exe` на ПК обычным двойным щелчком. Установщик, права администратора, Python, .NET и Java для работы не нужны.
5. Нажми **Найти телефон**. Если поиск не сработал, введи адрес с экрана телефона, например `192.168.1.42:8080`.
6. Введи шестизначный код с телефона и нажми **Подключить**. Должны появиться картинка и статус `LIVE`.
7. В OBS, Discord, браузере или другом приложении выбери видеоустройство **PhoneCam**. Если программа была открыта до регистрации камеры, перезапусти её.

На рабочем столе лежат EXE и APK; полная документация и резервные копии находятся в папке **PhoneCam — готово**.

## Как пользоваться

- Поверни телефон горизонтально для широкого кадра. Вертикальная картинка сохраняет пропорции и получает поля по бокам. Текст не зеркалится.
- Профиль **Баланс** запрашивает 1280×720, до 30 кадров/с, JPEG 75. **Экономия** — 640×360, до 15 кадров/с, JPEG 65; фактическое разрешение зависит от камеры. **Детали** — 720p, JPEG 90, больше трафика.
- Перед сменой камеры или профиля останови передачу на телефоне. После нового запуска появится новый код; введи его на ПК.
- **В трей** скрывает окно Windows, сохраняя передачу. Открой окно щелчком по значку или выйди через его контекстное меню. Закрытие окна крестиком останавливает приёмник.
- Экран телефона можно погасить: foreground-сервис продолжает работу. Некоторые прошивки ограничивают камеры в фоне; если это происходит, оставь приложение открытым и проверь ограничения батареи для PhoneCam.
- При кратком обрыве сети ПК пытается подключиться снова каждую секунду после сетевого таймаута. Через 2,5 секунды без свежего кадра камера показывает тёмную заливку вместо замершего лица.
- Кнопка **Тест камеры** на ПК выдаёт движущиеся полосы без телефона. Это проверяет локальную часть и регистрацию камеры.
- Показатель `fps` относится к входящим кадрам, `ms decode` — к декодированию и подготовке кадра на ПК. Это **не** измерение задержки от объектива до видеозвонка.

## Посмотреть в браузере

На телефоне нажми **Скопировать адрес для браузера**. Открой этот адрес на ПК, например `http://192.168.1.42:8080/?code=123456`. Это отдельный просмотр напрямую с телефона, без виртуальной камеры. Каждый просмотр добавляет сетевую нагрузку. После остановки и нового запуска на телефоне код меняется.

## USB, если Wi-Fi нестабилен

Необязательный вариант для разработчика: установи Android platform-tools, подключи телефон по USB, включи USB-отладку и подтверди доверие ПК на телефоне. Выполни `adb forward tcp:8080 tcp:8080`, включи передачу в Android-приложении, а в Windows-клиенте укажи `127.0.0.1:8080` и код телефона. Для удаления проброса: `adb forward --remove tcp:8080`. ADB не входит в EXE. Этот режим описан по механизму проброса, физический USB-тракт на данном ПК не проверялся.

## Если не заработало

| Симптом | Что проверить |
|---|---|
| Телефон не найден | Передача включена; одна Wi-Fi сеть; нет изоляции клиентов/VPN. Введи IP вручную: UDP-поиск необязателен. |
| `403` / connection code | Введён текущий код телефона. После повторного запуска сервиса код другой. |
| `Reconnecting` | Адрес, Wi-Fi, запущенная передача, виден ли поток в браузере. |
| Камеры нет в списке | Запусти EXE обычным пользователем, перезапусти программу звонков. Поддерживаются 64-битные DirectShow-приложения. |
| Тёмный кадр | Выключен приёмник или более 2,5 секунды нет свежего видео. Нажми «Тест камеры» для проверки Windows-части. |
| Низкий fps / нагрев | Выбери «Экономия», закрой лишние просмотры, попробуй 5 GHz Wi-Fi рядом с роутером. |
| APK не обновляет старую версию | Старый debug APK имеет другой ключ. Удали старое приложение и установи release APK заново. |
| Android просит разрешение на установку | Разрешение выдаётся выбранному приложению, которым открываешь APK. APK устанавливается вручную, не из магазина. |

## Что проверено и какие есть ограничения

Windows-тракт проверен через настоящий DirectShow-захват ffmpeg с сетевым тестовым источником. Проверены повороты, цвета, пропорции, обрывы, повреждённые данные, перезапуски и COM lifetime. Android: release-сборка, подпись APK, анализ lint, unit-тесты упаковки YUV и реального HTTP/UDP-сервера на JVM.

**Физического Android-телефона в доступных устройствах не было.** Реальный захват камеры телефона, расход батареи, задержка в твоём Wi-Fi, работа с выключенным экраном на твоей прошивке и совместимость с конкретным приложением звонков не подтверждены. Их нельзя честно считать проверенными по одной успешной сборке.

Текущий транспорт — **MJPEG по HTTP**, не аппаратный H.264. Это простая компактная реализация с ограниченными очередями, но с большим трафиком и нагрузкой на телефон, чем у правильно настроенного аппаратного H.264. Виртуальный выход — RGB32, 30 кадров/с; 1080p выход масштабирует вход, не добавляет детализацию. Передача микрофона, 32-битная DLL, автозапуск с Windows и облачный доступ не реализованы. DirectShow поддерживается не всеми приложениями: совместимость с Windows Camera и Media Foundation-only клиентами не обещается.

Видео и код передаются по локальному HTTP без шифрования. Код ограничивает случайный доступ к потоку, но не заменяет защищённый транспорт. Используй доверенную локальную сеть, не публикуй порт 8080 в интернете.

## Где находятся файлы и как удалить

EXE хранит встроенные компоненты в `%LOCALAPPDATA%\PhoneCam\1.1-<хеш>`. Новая сборка получает отдельный каталог, поэтому обновление не перезаписывает DLL, которую использует видеоприложение. Настройки — `%LOCALAPPDATA%\PhoneCam\settings.ini`, текущий статус — `status.txt` в каталоге сборки. Видео на диск не записывается.

Регистрация камеры выполняется для текущего пользователя, без UAC. Для удаления регистрации закрой приложения, использующие камеру, и запусти `PhoneCam.exe --uninstall`. Затем можно удалить EXE и каталог `%LOCALAPPDATA%\PhoneCam`. Старый исходный проект уже содержал отдельную системную регистрацию DLL; она не удалялась и может снова проявиться после удаления регистрации новой версии. Её удаление требует отдельного `regsvr32 /u` для старой DLL с правами администратора.

Исходники: `D:\work\My Projects\PhoneCam`. Начальная версия сохранена отдельным Git-коммитом. Разработка и сборка описаны в `DEVELOPMENT.md`, результаты — в `TEST_REPORT.md`.
